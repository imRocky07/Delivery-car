# 🚗 Delivery Car (Beta)

A small 2D Unity game where the player controls a delivery car to collect packages and deliver them to their designated owners while navigating around obstacles.

## 🎮 Gameplay

- Drive around the map to locate packages.
- Pick up a package to begin the delivery.
- The car changes color after picking up a package, indicating that it is carrying a delivery.
- Deliver the package to its correct destination to complete the objective.
- Use speed boost pickups to temporarily increase the car's movement speed.
- Colliding with obstacles causes the boost effect to be lost, encouraging careful driving.

## ✨ Features

- 🚗 Simple vehicle movement and controls
- 📦 Package pickup and delivery system
- 🎨 Dynamic car color change when carrying a package
- ⚡ Temporary speed boost mechanic
- 💥 Collision system that removes the active boost
- 🗺️ Basic level with obstacles
